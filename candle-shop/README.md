# Lueur Candles — демо‑магазин свечей

Модный, стильный, полностью статический магазин ароматических свечей. Без сборки и зависимостей: достаточно открыть `index.html` в браузере.

## Быстрый старт

- Откройте файл `index.html` в браузере.
- Вся логика находится в `app.js`.

## Возможности

- Поиск по названию и нотам
- Фильтры: семейства ароматов, теги, цена, только со скидкой, только избранное
- Сортировка: популярные, новинки, цена, рейтинг
- Избранное (локально сохраняется)
- Корзина: изменение количества, удаление, купоны `AROMA10` (−10%), `WELCOME15` (−15% от 6000 ₽), расчёт доставки и порога бесплатной доставки
- Быстрый просмотр товара (панель справа)
- Адаптивная вёрстка, тёмная тема (переключатель в шапке)
- Тосты‑уведомления, состояние сохраняется в `localStorage`

## Кастомизация

- Изменяйте список товаров в массиве `products` внутри `app.js`.
- Цвета/шрифты — через Tailwind CDN (см. `index.html`, блок `tailwind.config`).
